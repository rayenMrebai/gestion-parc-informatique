# Gestion de Parc Informatique

Cette application web permet la **gestion centralisée d’un parc informatique** au sein d’une usine.  

## 🏭 Structure hiérarchique
- **Projets** → regroupent plusieurs lignes
- **Lignes** → composées de postes
- **Postes** → chaque poste contient des équipements
- **Équipements** → PC, imprimantes, serveurs, etc.

## 🎯 Objectifs
- Centraliser et organiser les informations sur les projets, lignes, postes et équipements.
- Améliorer la traçabilité et le suivi du matériel informatique.
- Faciliter la gestion des utilisateurs (administrateurs et simples utilisateurs).

## 🔑 Fonctionnalités principales
- Gestion hiérarchique (projets → lignes → postes → équipements).
- Gestion des utilisateurs (administrateurs et utilisateurs).
- Recherche et filtrage avancés.
- Scan des équipements via **code-barres**.

## 🛠️ Technologies utilisées
- **Frontend / Backend** : Python (Streamlit)
- **Base de données** : MySQL
- **Autres** : Intégration de scan de codes-barres / QR
